## README.md

```markdown
# 設計書レビュー用ドキュメント

> **⚠️ 重要**: このディレクトリのファイルは `docs/design/` の内容を **人間向けに変換した生成物** です。
> 設計書の内容を変更する場合は、必ず元の `docs/design/` ファイルを修正してください。
> このディレクトリのファイルは `/humanize-design` で再生成されます。

## 元設計書との対応表

| このディレクトリ | 元設計書 |
|--------------|--------|
| 00-設計サマリー.md | docs/design/概要.md, 方式設計.md |
| 01-画面一覧と遷移.md | docs/design/screens/画面遷移.md |
| screens/SCR-XXX-*.md | docs/design/screens/SCR-XXX-*.md |
| 02-API仕様サマリー.md | docs/design/api/*.yaml |
| 03-データモデルサマリー.md | docs/design/DB定義.md, tables/*.md |

## 読み方

1. **全体を把握したい** → `00-設計サマリー.md` のアーキテクチャ図・フローから
2. **特定の画面をレビューしたい** → `01-画面一覧と遷移.md` で画面 ID を確認 → `screens/SCR-XXX-*.md`
3. **API の仕様を確認したい** → `02-API仕様サマリー.md`（詳細は元 YAML を参照）
4. **DB 構造を確認したい** → `03-データモデルサマリー.md`
```
